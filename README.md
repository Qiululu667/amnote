<h1 align="center">AM·Note</h1>

<p align="center">
  macOS 上的本地 Markdown 笔记浏览器。<br>
  把电脑里一个或几个文件夹当成笔记本来搜、来读、来改。<br>
  文件留在原地，不搬家，也不上传。
</p>

## 它解决什么问题

电脑里已经攒了一堆 `.md`，还有几份从别处导出的 `.html`。它们散在下载、桌面、某个项目文件夹里，各自安好。

想找一句话，得先想它在哪个文件夹；想改一段，得挑一个编辑器打开。云笔记倒是能装下，但要先把文件搬进去——搬进去之后，它们就不是你的文件了。

AM·Note 不搬。选一个文件夹，它给你一个像浏览器一样轻的窗口：⌘K 搜的是这个文件夹，标签页里读的是原来那些文件。改完，还是那些文件。文件夹散在好几处，就多选几个，一个窗口一起看。

![开始页：问候、笔记本条、「上次停在」和最近打开](docs/home.png)

## 它是怎么工作的

1. 第一次打开时挑一个文件夹，或者让它新建一个。任何文件夹都行，空的也行。这个文件夹就是一个**笔记本**。
2. 它在这个文件夹里建一个 `.amnote/`，放索引和编辑备份。你的笔记一个字节都不动。
3. 窗口只有两行：上面一行是标签页、搜索和设置，每篇笔记占一个**标签页**；下面一行写着这份文件在哪、能对它做什么。搜整个文件夹按 **⌘K**。
4. 散在别处的文件夹想一起看，再添一个笔记本就是。只有一个笔记本时，界面和路径跟以前完全一样。

## 能做什么

**找**

- ⌘K 是唯一的搜索入口。打字，第一行就是「在全部笔记中搜索“…”」，回车搜正文，⌘ 回车在新标签里搜。
- 第一行下面是动作和笔记标题，上下键选，回车打开。文件名和正文都搜，搜的是这个文件夹，不是网上。
- 在开始页直接打字也行，第一个字就把面板叫出来。
- 开始页问候语下面是一行文件夹芯片：库里的第一层文件夹，最后一枚是「已收藏」。点一下进去看有什么，⌘ 点开新标签；里面还有子文件夹的话，下一行接着列，上面一行面包屑随时退回来。
- 开始页、文件夹里和「已收藏」都是一份目录：一行一篇，左边一枚小徽标（厚厚一小块圆角玻璃，md 那枚泛淡紫、浮着 `M↓`，html 那枚泛灰、浮着 `</>`），中间是标题，一串点把眼睛引到最右边的时间，底下一行灰字是正文的第一句。还是可以按「全部 / Markdown / HTML」筛。

**读**

- md 和 html 都在标签里打开。库里的网页原样渲染，不用转格式。
- 库里的 html 是在沙箱里渲染的：脚本照跑，图照画，但那一页拿不到 `localStorage`、`sessionStorage`、`cookie`、`indexedDB`（碰一下就抛 SecurityError），也发不出请求到本机的服务。所以要存的东西写进 md，别让页面自己记——下次打开它什么都不记得。
- 开始页有「最近打开」，还有一张「上次停在」的大卡——上次读到哪篇，一眼看见，点「接着读」回去。列表上的时间是你上次打开它的时刻，大卡那一篇不在下面再列一遍。
- 开始页平时不显示状态；只有正在整理（「扫描中…」）或服务断开时，问候语旁边才出一枚小点。窗口底下也不挂状态栏。
- 在笔记上点右键选「收藏」（文档头右边那颗星也一样），收起来的都在「已收藏」那枚芯片里。
- 正文上面那一行是文档头：左边是大纲开关、关联开关和这份文件的路径，点一下路径就把它拷走，⌘ 点其中一段文件夹名，在新标签里打开那个文件夹；右边依次是收藏、在访达中显示、分享、在新窗口打开，再往右是专注、「⋯」和「编辑」。
- 左侧大纲：标题层级一目了然，读到哪一节自动高亮，点一下跳过去。⌥⌘I 收起或叫回来。
- 左侧「关联」：这篇周围有什么——所在文件夹（能一路展开成整本的文件树，当前这篇高亮）、同一篇的其他版本（`_v1`、`v3 终版`、`20260827_` 开头、同名的 .html 都归到一起）、链到谁和被谁链到。默认关着，⌥⌘R 叫出来；它和大纲共用左边那一栏，一次只显示一个。
- 专注阅读：点 ⤢，文档头、大纲和关联一起收起来，只剩正文；鼠标碰一下窗口顶边它们就滑回来，Esc 退出。
- 正文里写的 `- [ ]` 是真能点的勾选框：读着就能勾，勾完文字变灰划一道线，那一行的 `[ ]` 当场变成 `[x]` 写回文件——只改方括号里那一个字。编辑态里回车，接着起下一条。

![读一篇笔记：上面两行，左边大纲](docs/reading.png)

**写**

- 双击正文进编辑，光标落在你双击的那一段。⌘E 也行。
- 选中文字浮出格式条：加粗、标题、列表、引用、链接、表格、加行加列。
- 停笔两秒自动存，右上角显示「已保存 14:29」。⌘S 立刻存一次，写完点「完成」收工。
- 这份文件如果在别的编辑器里被改过，保存时会拦一下，让你选「保留我的」还是「改用对方的」。
- 点「看 Markdown 源码」切到整篇源码，改完再切回来。
- 截图直接粘进正文，图片落在这篇旁边的 `_图/` 里。

![编辑同一篇：格式条和「完成」](docs/editing.png)

**整理**

- ⌘T 开新标签先到开始页；点「新建随手记」写下第一个标题，文件会自动照标题改名。
- ⌘⇧T 把刚关掉的标签搬回来。
- 在访达中显示、分享、在新窗口打开，都是文档头右边那几个小图标；拷贝路径点一下路径就行。打印和「打开所在文件夹」在「⋯」里。
- 建错的随手记：「⋯」→ 移到废纸篓，或按 ⌘⌫；几秒内可以在提示里撤销，文件在系统废纸篓里也能找回。
- 双击访达里的 `.md`，用它打开。会开在一个新标签里，正在读的那篇不受影响。

**多个笔记本**

- 一个文件夹就是一个**笔记本**。添了第二个之后，开始页问候语下面多一行笔记本条：`全部 | ● 工作 | ● 读书 | ☆ 已收藏 | ＋`，文件夹芯片、列表、搜索范围和新建落点都跟着它走。
- 每本一种颜色。列表、路径芯片、标签页和 ⌘K 结果上都带这枚色点，一眼知道在哪一本里；紫色仍旧只表示「选中」。
- 「全部」是总览：「上次停在」、最近和搜索跨着所有笔记本。想看文件夹芯片，先点一本——那一刻的页面就是从前的开始页。
- 新建随手记（⌥⌘N）落在笔记本条选中的那本，选着「全部」时落默认那本。提示条写「已在 ● 工作 新建」，点「换一个」还能挪到别本去。
- 多本时路径带上本名，像 `工作/会议/周会.md`。每个笔记本各有各的 `.amnote/`；文件夹一时找不到（外置盘没插），那枚芯片压灰写「找不到」，不会替你移除。
- **只有一个笔记本时，和以前完全一样**：没有笔记本条，没有色点，路径不带前缀。

**设置**

- ⌘, 打开，或者点右上角那颗 ⚙。六页：个人、阅读与外观、笔记库、Agent、高级、关于。
- 个人：起个名字、放张头像，开始页就按时段跟你打招呼（「早上好，露露」）。资料只留在这台 Mac 上。
- 界面语言：跟随系统 / 简体中文 / 繁體中文（香港）/ English。壳的菜单和网页一起换，切换后会重新载入页面。
- 两款新的阅读字体：**苹方-港**有极细到中粗六档字重可选；**新细明体**本机没装的话，会从已装的 Microsoft Office 里把那一份借出来用，连 Office 都没有就退到宋體-繁。
- 阅读与外观：跟随系统 / 浅色 / 深色，正文字体（黑体、宋体、等宽、苹方-港、新细明体，卡片上先看到样子），字号 15–21，行距紧凑 1.6 / 舒适 1.8 / 宽松 2.0，栏宽窄 620 / 标准 690 / 宽 820，还有「打开文档时默认显示大纲」。换深色时标题栏跟着一起变，和窗口是一块的。
- 笔记库：用的是哪些文件夹——添加、改名、换颜色、设为默认、移除都在这里；收了多少篇、上次整理是什么时候，也可以让它重新整理一遍；随手记放在哪个文件夹；哪些文件夹不收录（后面这两样每个笔记本各存各的）。
- 高级默认折着——跳过的文件、本机服务端口都在里面。端口只认第一个笔记本那一格：一个进程一个端口。关于那页有版本号、「检查更新」和自动检查的开关。

## 它不做什么

- 不同步、不上传、不要账号。日常完全离线，只有你按「检查更新」时才联网。
- 不复制你的文件，也不改你的文件夹结构。
- 不锁格式。同一份文件随时可以用别的编辑器打开，两边一起用也行（它会提醒你有冲突）。
- 只认 `.md` 和 `.html`。别的类型的文件正文照样进索引、搜得到，但不在窗口里列出来，也不渲染。

## 安装

到 [Releases](https://github.com/Qiululu667/amnote/releases) 下载 `AMNote-mac.zip`，解开得到 `AM·Note.app`。

**第一次请右键图标 → 打开**，不要双击。没花钱做苹果签名，系统会问一次，点开就行。

需要 macOS 12 或更新。不用账号，不用联网。

想自己编：仓库根目录跑 `python3 src/build_app.py`，编完的 app 在 `dist/`。

## 第一次打开

1. 右键 `AM·Note.app` → 打开。
2. 窗口上是一张欢迎卡，两个选择：**新建一个笔记库**，在「文稿」里建一个 `AM·Note` 文件夹，附一篇欢迎笔记；**使用已有文件夹**，挑一个已经放着 Markdown 或网页的文件夹。
3. 选完它整理一遍，告诉你找到了多少篇，然后就是开始页。第一次进去还有一张「第一次来？三件事就够了」的小卡片，点「知道了」就不再出现。

选完会记住。下次打开先到开始页，不会自动跳进上次那篇。

空文件夹也能用：能搜（0 条），能新建随手记。随手记默认落在所选文件夹下的 `随手记/`，没有就自动建。

上次那个文件夹要是被挪走或者删了，它不会退出，只会问你「重新选择位置…」还是「新建一个笔记库」。文件不会丢，只是它找不到那个文件夹了。

两本以上时，找不到的只是那一本：笔记本条上它压灰写「找不到」，设置里那一行有「重新定位…」，别的本照用。

想先试试，可以把它指到仓库里的 [`examples/demo-vault/`](examples/demo-vault)。

## 管理笔记本

设置（⌘,）→ 笔记库。两本以上时这一段是一列笔记本：色块点开八色盘，名字就地改，灰字路径点一下在访达里打开，右边是「设为默认」和「移除」。列表下面是「添加笔记本…」，菜单「库 → 添加笔记本…」是同一件事。

移除只是把这条登记注销掉：文件不动，`.amnote/` 也留着，哪天再添回来就接着用。至少留一个。文件夹被挪走的那本压灰，那一行有「重新定位…」。

只有一本时这一段还是从前那张「当前笔记库」卡片，「更换文件夹…」也还在。

## 更新

菜单「AM·Note → 检查更新…」，设置的「关于」那页也有同一颗按钮。有新版可以直接装，装完会退出再打开，笔记还在原来的文件夹里。

从第二次启动起，大约一天查一次 GitHub Releases；菜单里和设置里都能关掉「自动检查更新」。只问版本号和安装包，不上传任何东西。

已经装了旧版的，需要先手动下一次带「检查更新」的版本（5.1.0 起）；之后就不用再去 GitHub 了。

## 文件都放在哪

你的笔记还在原来那个文件夹里。多出来的只有一个 `.amnote/`：

| | |
| --- | --- |
| `fulltext.db` | 全文索引 |
| `changes.jsonl` | 改动流水（谁在什么时候动了哪份） |
| `backups/` | 编辑备份，每份文件留最近 10 版 |
| `config.json` | 这个库的设置（跳过哪些目录、端口范围、随手记目录…） |

删掉 `.amnote/`，笔记一份不少，只是下次打开要重新扫一遍。

- 随手记默认落在库里的 `随手记/`，目录名在设置 → 笔记库 里改。
- 粘贴进正文的图片，落在那份 md 旁边的 `_图/`。
- 库根还可能多两份，都是设置 → Agent 里点出来的，不点就没有：`AGENTS.md`（给在这个文件夹里跑的 agent 的说明）和 `库地图.md`（导出的库地图，重新导出会整份盖掉，别在里面手写东西）。
- 笔记本名单在 `~/Library/Application Support/AMNote/notebooks.json`：每本的名字、颜色和路径。它只记「用了哪些文件夹」，笔记一个字都不在里面。
- 服务的端口和口令在同一个目录下的 `portal.port` 和 `portal.token`（口令文件 0600）。还有 `profile.json` 和 `avatar.img`——你的昵称和头像，只在这台 Mac 上。

## 给 Agent / 脚本的本地接口

AM·Note 开着的时候，这台 Mac 上的 AI 助手可以搜索和读写这个库。只在本机，不联网。

**三步接上**

1. 设置（⌘,）→ Agent。
2. 用 Claude Code 就点「安装 Skill」；用 Codex 或别的工具，点「拷贝 MCP 命令」或「拷贝 MCP 配置」，贴进它自己的配置里。
3. 回 Claude Code 直接说「帮我在笔记里找一下上次那份发布检查表」。

Skill 教它的是一套顺序：先问**有哪些笔记本**，再看**库地图**知道有哪些目录，然后**搜索**定位，最后只**读那一节**——不用把整个库灌进上下文。

在库文件夹里跑的 agent（Codex、Cursor…）还可以点「在库根生成 AGENTS.md」，它开工先读到同一套规矩。旁边那颗「导出到库根」写一份 `库地图.md`，AM·Note 没开着时也能看。

**命令行 `amnote`**

设置 → Agent → 命令行工具 →「安装」，在 `~/.local/bin/amnote` 建一条软链接，指到 app 里的 `AM·Note.app/Contents/Resources/amnote`。不装也行，直接叫那个绝对路径一样使。

```bash
amnote notebooks                              # 有哪些笔记本、哪本是默认
amnote map                                    # 库里有哪些目录、每篇讲什么
amnote search "报销" --dir 工作手记 --since 7   # 空格分词＝AND，还能 --type md,pdf
amnote outline 工作手记/报销.md                # 这份有哪些小节
amnote read 工作手记/报销.md --section "发票"   # 只读那一节
amnote recent                                 # 最近改了什么
amnote new "会议纪要 0906" < 正文.md           # 新建，默认落在随手记目录
amnote save 工作手记/报销.md < 正文.md          # 整篇覆写；要先 read 过这份（它记得你读到的版本），或加 --based/--force

# 两本以上时：路径以笔记本名开头，多数命令加 -n 名字只看一本
amnote read 工作/会议/周会.md
amnote map -n 读书
amnote search "周会" --notebook 工作            # search 和 recent 上的 -n 是「要几条」，只能写长的
amnote new "会议纪要 0906" -n 读书              # 不给 -n 就落在默认那本的随手记目录
```

路径一律是**库相对路径**；两本以上时它以笔记本名开头（`工作/会议/周会.md`），`amnote notebooks` 列出有哪些本。每条都能加 `--json` 拿原样的 JSON，`--agent 名字` 给这次改动署名。

AM·Note 没开着时，只读的那几条会用 `.amnote/` 里上一次的索引接着答（会在 stderr 说一声），写不了。

退出码：0 成功 · 1 用法错（含「没读过就 save」）· 2 AM·Note 没在运行 · 3 冲突（这份在你读完之后被别处改过，加 `--force` 才盖）· 4 服务端拒绝。

**MCP**

```bash
claude mcp add amnote -- /路径/到/amnote mcp
```

Codex 的 `~/.codex/config.toml` 里加：

```toml
[mcp_servers.amnote]
command = "/路径/到/amnote"
args = ["mcp"]
```

九个工具：`list_notebooks`、`search_notes`、`note_map`、`read_note`、`note_outline`、`recent_notes`、`note_links`、`create_note`、`save_note`。多本时先叫 `list_notebooks`；`search_notes`、`note_map`、`recent_notes`、`create_note` 都有一个可选的 `notebook`。设置 → Agent 里那两颗「拷贝」按钮已经把路径填好了。

**直接走 HTTP**

写脚本，或者用别的语言接，直接叫路由也行。服务只监听 `127.0.0.1`，端口默认在 8870–8900 之间挑一个，**永不输出 CORS 头**——浏览器里的网页碰不到它。读的路由不要口令，写的路由（所有 POST）要在头里带 `X-AMN-Token`。

```bash
D=~/Library/Application\ Support/AMNote
P=$(cat "$D/portal.port")
T=$(cat "$D/portal.token")

# 先确认服务还活着，不是 200 就别重试，改叫 amnote（它会退到上次的索引）
# /__status 里的「模式」是「单」还是「多」，「笔记本」是那份名单
curl -s -m 3 -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:$P/__status"

# 有哪些笔记本：名字、颜色、路径、收录、哪本是默认
curl -s "http://127.0.0.1:$P/__notebooks"

# 库地图：一份 Markdown 的「这个库里有什么」，开工先看它。
# dir= 只画一个目录，max= 每个目录列几篇（默认 20），depth= 目录深度
curl -sG "http://127.0.0.1:$P/__map" --data-urlencode "dir=工作手记"

# 搜整个库。中文词要用 --data-urlencode；n 默认 200，上限 500。
# 还能筛：dir=目录、type=md,pdf、since=7 或 since=2026-09-01、sort=mtime、offset=20
curl -sG "http://127.0.0.1:$P/__search" \
     --data-urlencode "q=检查表" --data-urlencode "n=10" \
     --data-urlencode "dir=工作手记" --data-urlencode "since=7"

# 这一份有哪些小节：每个标题的级、文本、行号
curl -sG "http://127.0.0.1:$P/__outline" --data-urlencode "path=工作手记/发布检查表.md"

# 读一份 md 的源码。整份，或者 section=标题 只要那一节、lines=5-40 只要那几行
curl -sG "http://127.0.0.1:$P/__raw" \
     --data-urlencode "path=工作手记/发布检查表.md" --data-urlencode "section=打包"

# 这篇指向谁、谁指向它
curl -sG "http://127.0.0.1:$P/__links" --data-urlencode "path=工作手记/发布检查表.md"

# 最近改了什么。days 默认 7、上限 365，n 默认 50、上限 500
curl -sG "http://127.0.0.1:$P/__recent" --data-urlencode "days=7"

# 库里有什么：目录树 + 全部 md/html + 随手记
curl -s "http://127.0.0.1:$P/__tree"

# 写回去。要口令；「基于」填上一次读到的「改于」，别人改过就会被拦下来。
# 带上名字，列表上会显示是谁改的
curl -s -X POST "http://127.0.0.1:$P/__save" \
     -H "X-AMN-Token: $T" -H "X-AMN-Agent: 我的脚本" \
     --data-binary '{"路径":"工作手记/发布检查表.md","正文":"# 标题\n\n正文\n","基于":"2026-09-05 09:42:00"}'

# 移到系统废纸篓。只搬位置不改内容，认 .md / .html / .htm
curl -s -X POST "http://127.0.0.1:$P/__trash" -H "X-AMN-Token: $T" \
     --data-binary '{"路径":"工作手记/建错了.md"}'

# 把刚才那份挪回原位。撤销表只在内存里，服务重启过就撤不回来了，去废纸篓找
curl -s -X POST "http://127.0.0.1:$P/__untrash" -H "X-AMN-Token: $T" \
     --data-binary '{"路径":"工作手记/建错了.md"}'
```

`/__search` 每条命中带 `路径`、`标题`、`类型`、`改于`、`大小`、`分数`，下面挂几段 `片段`，每段带 `行`（行号）和 `小节`（命中落在哪个标题下）。照着 `小节` 去 `/__raw?section=` 取那一节，别整份读回来。

两本以上时路径一律以笔记本名开头，`/__search`、`/__recent`、`/__changes`、`/__map`、`/__config`、`/__archive` 都认 `nb=名字`（逗号可以写好几本）限定范围；`dir=工作/会议` 自带前缀，等于也限定了那一本。`/__changes` 的序号是按本各自数的，要用 `since=` 取增量就一次只问一本。

`X-AMN-Agent` 所有 POST 都认：流水上记成「来源 Agent · 代理 你的名字」，列表里那一行的标题后面也会多一枚 `✦ 你的名字`。

改文件内容的只有 `/__save` 和 `/__task` 两条（后者只把某一行 `- [ ]` 方括号里那一个字翻过来），只写库根以内的 `.md`，写之前先留一版备份。另外两条搬位置的是 `/__trash` 和 `/__untrash`：文件原样进出系统废纸篓，一个字节都不动。备份目录、缓存目录、隐藏目录一律不给动。

## 常见问题

**双击打不开，说文件已损坏 / 无法验证。** 没做苹果签名。右键图标 → 打开，系统会问一次，点开就行。

**索引在哪？** 在所选文件夹里的 `.amnote/`。它不进索引，也不会被搜到。

**删了 `.amnote/` 会怎样？** 笔记一份不少。下次打开重新扫一遍，编辑备份和改动流水会丢。

**能同时管好几个文件夹吗？** 能。设置 → 笔记库 → 「添加笔记本…」，加进来的每个文件夹是一个笔记本，一个窗口一起看。各自的 `.amnote/` 各存各的；移除只是注销登记，文件不动。

**和 Obsidian 或别的编辑器同时开着，会打架吗？** 不会覆盖。你在这边保存时，如果那份文件在别处被改过，顶上会出来一条提示，让你选「保留我的」还是「改用对方的」。

**Agent 改了我的笔记我怎么知道？** 列表里那一行会多一枚 `✦ Claude Code`——这一篇最近一次是本机哪个 AI 助手写的，七天内都标着。要看细账翻 `.amnote/changes.jsonl`，每条都记着「来源」和「代理」。

**昵称和头像存在哪？** `~/Library/Application Support/AMNote/` 下的 `profile.json` 和 `avatar.img`。它们跟着这台 Mac 走，不进笔记本，也不上传，添一本、换一本都不用重设。不想被打招呼，设置 → 个人 里把「开始页向我问好」关掉。

**要联网吗？** 不要。只有检查更新时会访问 GitHub。
